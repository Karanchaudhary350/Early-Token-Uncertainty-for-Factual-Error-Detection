# Dataset and experiment data

- `frozen/TruthfulQA_source.csv`: source snapshot from earlier research artifact; **review TruthfulQA licensing and redistribution permissions before public push**.
- `frozen/frozen_sample_ids.csv`: deterministic 100-question sample (20 pilot / 80 held-out).
- `outputs/`: actual saved generations, features and manifest from the Colab run.
- `annotations/AI_first_pass_UNVERIFIED.csv`: AI-first-pass labels; **not independently verified ground truth**.

See `docs/DATA_ACCESS.md` for dataset access and checksums. No model weights are included.
